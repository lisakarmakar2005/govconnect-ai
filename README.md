# GovConnect AI

**From Government Problems to Proven Innovation**

GovConnect AI is an AI-assisted government innovation procurement platform designed to connect government departments with eligible startups and support the journey from identifying public-sector challenges to evaluating solutions and managing controlled pilots.

## Overview

The platform provides separate workflows for:

* Government Officers
* Startups

It demonstrates how government challenges can be structured, evaluated, matched with potential startup solutions, tested through controlled pilots, and prepared for scale-up and procurement.

> **AI Disclaimer:** AI provides recommendations only. Final procurement decisions and statutory approvals remain with the authorized government officer and applicable rules.

## Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd govconnect-ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL shown in the terminal.
